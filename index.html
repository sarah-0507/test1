# HTML5 核心 2026 年學習紀錄

🌐 建立結構完整的網頁骨架

在現代網頁設計中，HTML 負責**內容與骨架（結構）**，而 CSS 負責**視覺與外觀（風格）**。 透過將結構與樣式分開在不同的檔案中，能讓專案更好維護與擴展。

使用適當的語意化標籤（例如 <header>、<main>、<article> 與 <footer>）， 不僅可以讓程式碼更容易被團隊閱讀，還能大幅提升搜尋引擎（SEO）的收錄效果。
